# 一人回し機能 要件定義

## 概要

遊戯王NEXTに「一人回し機能」を追加し、特定条件下でのカードの動き方を確認できるようにする。

## 目的

**主目的**: コンボ確認、初動確認、カードの相互作用確認
**目的外**: 本番のデュエルシミュレーション、対戦相手の行動再現

### ユーザーがやりたいこと

1. デッキを回して初動の手札を確認する
2. 特定のコンボが決まるか手順を確認する
3. サーチ先のカードを確認する
4. 手札誘発のタイミングを確認する
5. 特定の場面を作ってカードの挙動を確認する

---

## 機能要件

### 必須機能

| 機能 | 説明 | 優先度 |
|------|------|--------|
| 手札を引く | デッキから指定枚数ドロー | 高 |
| 任意のカードを手札に加える | サーチシミュレート | 高 |
| カードを場に出す | 手札から場へ | 高 |
| カードを墓地へ送る | 任意のカードを墓地へ | 高 |
| カードを除外する | 任意のカードを除外へ | 高 |
| デッキをシャッフル | ランダムな手札を引く | 高 |
| リセット | 初期状態に戻す | 高 |

### あると便利な機能

| 機能 | 説明 | 優先度 |
|------|------|--------|
| 特定カードをデッキトップに置く | 初動確認用 | 中 |
| 特定カードをデッキボトムに置く | 中 |
| カードの表示形式変更 | 攻撃/守備/裏側 | 中 |
| 手札枚数指定ドロー | 5枚ドロー等 | 中 |
| 状態保存 | 練習状態を保存 | 低 |
| 操作履歴 | 何をしたか記録 | 低 |

### 不要な機能

| 機能 | 理由 |
|------|------|
| ターン/フェーズ管理 | 本番シミュレートが目的ではない |
| 相手プレイヤーのフィールド | コンボ確認には不要 |
| ライフポイント管理 | 本番シミュレートが目的ではない |
| 厳密なルール適用 | 自由な操作が目的 |

## 画面レイアウト

### 基本構成

```
+------------------+-------------------+
|                  |                   |
|  左側/中央       |    右側エリア     |
|  (プレイエリア)  |    (既存のまま)   |
|                  |                   |
+------------------+-------------------+
```

### プレイエリア（1プレイヤーのみ）

```
+------------------------------------------------------------+
| [手札エリア: 横並び、スクロール可能]                        |
| [H1][H2][H3][H4][H5][H6][H7][H8]...                        |
+------------------------------------------------------------+
| [モンスターゾーン: 5枠]    [デッキ: 山札]                   |
| [M1][M2][M3][M4][M5]       [D:40枚]                        |
+------------------------------------------------------------+
| [魔法罠ゾーン: 5枠]        [墓地] [除外] [EX]              |
| [S1][S2][S3][S4][S5]       [G:12][E:3][EX:15]              |
+------------------------------------------------------------+
```

### 各エリアの役割

| エリア | 役割 | 表示 |
|--------|------|------|
| 手札 | 現在の手札 | 全カード表示（スクロール可） |
| モンスターゾーン | 場のモンスター | 5枠 |
| 魔法罠ゾーン | 場の魔法罠 | 5枠 |
| デッキ | 山札 | 枚数のみ表示（クリックで操作） |
| 墓地 | 墓地のカード | 枚数表示（クリックで一覧） |
| 除外 | 除外されたカード | 枚数表示（クリックで一覧） |
| EX | エクストラデッキ | 枚数表示（クリックで一覧） |

### 2デッキモード

```
+------------------------------------------------------------+
| [デッキA]  手札A  [M1-M5] [S1-S5] [G][E][EX]              |
+------------------------------------------------------------+
| [デッキB]  手札B  [M1-M5] [S1-S5] [G][E][EX]              |
+------------------------------------------------------------+
```

上下ではなく、同じ構成を2つ並べる形で、カードの動きを比較確認できる。

## カード操作設計

### 基本操作

| 操作 | 方法 | 説明 |
|------|------|------|
| ドロー | デッキクリック | 1枚引く |
| 複数ドロー | デッキ右クリック→「X枚ドロー」 | 指定枚数引く |
| サーチ | デッキ右クリック→「検索」 | デッキからカードを選んで手札に |
| トップに置く | デッキ右クリック→「トップに置く」 | 特定カードをデッキトップに |
| 場に出す | 手札カードをドラッグ→場 | モンスター/魔法罠ゾーンへ |
| 墓地へ | カード右クリック→「墓地へ」 | 任意のカードを墓地へ |
| 除外へ | カード右クリック→「除外へ」 | 任意のカードを除外へ |
| シャッフル | デッキ右クリック→「シャッフル」 | デッキをシャッフル |
| リセット | リセットボタン | 全て初期状態に戻す |

### コンテキストメニュー

**デッキ**
```
┌─────────────────────┐
│ ドロー（1枚）        │
│ ドロー（5枚）        │
│ ─────────────────── │
│ 検索して手札に加える  │
│ トップに置く          │
│ ボトムに置く          │
│ ─────────────────── │
│ シャッフル            │
└─────────────────────┘
```

**手札のカード**
```
┌─────────────────────┐
│ モンスターゾーンへ    │
│ 魔法罠ゾーンへ        │
│ ─────────────────── │
│ 墓地へ送る            │
│ 除外する              │
│ デッキに戻す          │
└─────────────────────┘
```

**場のカード**
```
┌─────────────────────┐
│ 墓地へ送る            │
│ 除外する              │
│ 手札に戻す            │
│ デッキに戻す          │
└─────────────────────┘
```

**墓地/除外/エクストラ（枚数表示部分）**
```
┌─────────────────────┐
│ 一覧を表示            │
└─────────────────────┘
→ クリックでダイアログ表示、カード選択で操作
```

### キーボードショートカット

| ショートカット | 操作 |
|----------------|------|
| D | ドロー（1枚） |
| Shift+D | 5枚ドロー |
| S | シャッフル |
| R | リセット |
| Ctrl+Z | Undo |
| Escape | 選択解除 |

### Undo/Redo

- 全操作をUndo可能
- 最大30手まで履歴保持

## 技術方針

### 既存資産の活用
- `src/stores/deck-edit.ts` の状態管理パターン
- `DeckCard.vue` のカード表示コンポーネント
- Fisher-Yatesシャッフルアルゴリズム
- FLIPアニメーション

- プラクティス状態管理ストア（`usePracticeStore`）
- プレイエリアコンポーネント（`PracticeField.vue`）
- 手札・場の表示コンポーネント
