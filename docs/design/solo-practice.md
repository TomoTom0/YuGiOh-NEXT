# 一人回し機能 要件定義

## 概要

遊戯王NEXTに「一人回し機能」を追加し、特定条件下でのカードの動き方を確認できるようにする。

## 目的

**主目的**: コンボ確認、初動確認、カードの相互作用確認
**目的外**: 本番のデュエルシミュレーション、対戦相手の行動再現

### ユーザーがやりたいこと

1. デッキを回して初動の手札を確認する
2. 特定のコンボが決まるか手順を確認する
3. サーチ先のカードを確認する
4. 手札誘発のタイミングを確認する
5. 特定の場面を作ってカードの挙動を確認する

---

## 配置場所

デッキ編集ページおよびデッキ閲覧ページで、デッキレシピを表示している部分と切り替えて表示される。

---

## 画面構成

画面は **practice-area**（フィールド部分）と **right-area**（デッキ/検索パネル）の2つに完全に分離されており、互いに影響しない。

### practice-area

カードを実際に配置・操作するフィールド。1デッキモードと2デッキモードで構成が変わる。

### right-area

デッキ情報、カード検索、プレイヤー情報パネルなどを表示する右側パネル。practice-area とは独立。

---

## 画面レイアウト

### 1デッキモード（P1のみ）

公式デュエルフィールドに準拠した配置。

```
+--------+----+----+----+----+----+--------+--------+
| Field  | M1 | M2 | M3 | M4 | M5 |  GY    | Banish |
+--------+----+----+----+----+----+--------+--------+
| Extra  |ST1|ST2|ST3|ST4|ST5|   Deck   |
+--------+----+----+----+----+----+---------+
| [H1][H2][H3]...[Hn]               |  Temp  |
+---------------------------------------------+
```

| 行 | ゾーン | 説明 |
|----|--------|------|
| Row 1 | Field / M1-M5 / GY / Banish | フィールド魔法、モンスターゾーン(5枠)、墓地、除外 |
| Row 2 | Extra / ST1-ST5 / Deck | エクストラデッキ、魔法罠ゾーン(5枠)、メインデッキ |
| Row 3 | Hand / Temp | 手札、一時置き場 |

- 全ゾーンへの配置は自由（ルール判定なし）

### 2デッキモード（P1 + P2）

P2フィールドが practice-area の上部へスライドインして表示される。P1フィールドは下方向へスライドする（押し下げられる）。

**EMZ（エクストラモンスターゾーン）は両プレイヤー共通**（上下フィールドの間に1列として配置）。重複しない。

```
+--[ P2フィールド（上からスライドイン） ]--+
| P2 Hand   | P2 ST5..ST1 | P2 Extra  |  <- P2は点対称なので左右・上下が逆
| P2 Deck   | P2 GY/Banish| ...       |
+--[ EMZ1 ]--[ EMZ2 ]--------------------+  <- P1/P2共通
+--[ P1フィールド（下方スライド後） ]------+
| Field | M1..M5 | GY | Banish          |
| Extra | ST1..ST5    | Deck            |
| Hand                        | Temp    |
+------------------------------------------+
```

**P2フィールドの点対称仕様:**
- P2フィールドは P1 の 180° 点対称配置
- P1 の Deck 位置（右下）は P2 では左上に相当
- P1 の GY 位置（右上）は P2 では左下に相当
- P1 のモンスターゾーン M1（左端）は P2 では右端のスロットに対応
- カードの向き（縦/横）も点対称: P1 の横向き = P2 では横向き（回転方向が逆）
- P2フィールドはそのままではなく、視覚的に上下左右を反転した状態で表示

## 各ゾーンの表示仕様

**カードの表示状態:**
- 表向き（通常表示）
- 横向き（守備表示等）
- 裏向き: デッキ・エクストラデッキゾーンでは完全な裏面のみ表示。それ以外のゾーンでは**カードイラストを半透明表示し、その上に裏面を重ねて表示**（内容が見える）
- 重ね表示（右上/左上/右/左にずらしながら重ねる、枚数表示付き）

**デッキの表示:**
- メインデッキ: 裏向きでずらさずに重ねる。内容は原則非公開。手動で上・下に配置したカードのみ表示される
- エクストラデッキ: 裏向きでずらさずに重ねる。内容は確認可能
- どちらにも手動で表向き/裏向きカードを上・下に追加可能

**墓地/除外の表示:**
- 上位数枚をプレビュー表示
- ボタン押下で展開して全体を確認可能

**一時置き場（Temp）:**
- 手札の右側に配置
- カードを一時的に置けるエリア

### カードサイズ

手動設定（プリセット選択を設定画面で切替）

## 操作設計

### ドラッグ＆ドロップ

#### カスタムドラッグゴースト

HTML5 ネイティブのドラッグゴーストは非表示にし、カーソル追従のカスタムオーバーレイを代わりに使用する。

- ドラッグ中のカードはフィールド上で透明になる（元位置に残る）
- カーソル位置にカードのオーバーレイを表示
- ドラッグ中に裏向きで配置予定の場合、オーバーレイに裏面を半透明で重ねて表示

#### ドロップ位置

デッキ編集画面と同様の挙動: **ドロップした位置にカードが挿入され、既存カードがずれる**（単純にスタックトップ/ボトムへ追加するだけでない）。

#### ドロップクォーター UI

ゾーンへドラッグホバー時、ゾーン内を4分割（または2分割）したクォーターを表示し、ドロップ後の挿入位置と表面/裏面状態を視覚的に示す。

- 左右の挙動が同一のゾーン（カードなし、エクストラデッキ等）は左右を統合して2分割表示
- デッキゾーンは上段（左下配置 / 右上配置）と下段（シャッフル）を3分割表示
- 裏向きで配置される予定のクォーターは紫色でハイライト

#### ドラッグ中の右クリック回転

- ドラッグ中に右クリック（コンテキストメニュー）でカードの縦/横を切り替え
- Chrome では右クリックでドラッグがキャンセルされ `contextmenu` は dragend 直後に発火するため、200ms の猶予で検出する

### スロット単位の操作

各ポジション（スロット）のカード左上に配置:
- **クイック操作ボタン**: 代表的な操作（ドロー、墓地へ等）
- **メニューボタン**: ダイアログを開き、重なっているカード全体の表示と各種操作

### カード単位の操作

ダイアログ内や個別カードに対しても操作可能。

### 基本操作

| 操作 | 説明 |
|------|------|
| ドロー | デッキの上から1枚を手札の右端に追加 |
| デッキから直接移動 | デッキの上から1枚を墓地・除外などに直接追加 |
| 手動配置 | 表向き/裏向きでデッキの上・下にカードを配置 |
| シャッフル | メインデッキ、手札、エクストラデッキそれぞれで可能 |
| 場に出す | 手札カードをモンスター/魔法罠ゾーンへ |
| 墓地へ | 任意のカードを墓地へ |
| 除外へ | 任意のカードを除外へ |
| 手札に戻す | 場のカードを手札へ |
| デッキに戻す | カードをデッキの上・下に戻す |
| 一時置き場へ | カードをTempエリアに一時退避 |
| リセット | 全て初期状態に戻す（P1のみ） |
| ハードリセット | P1・P2ともに完全初期化、一時レシピも消去 |

## モード切替

- デッキ名の右にトグルボタンを配置
- practice モードへの切替・復帰時は**アニメーション**を伴う（フェード・スライド等）
- デッキ名フィールドには save/open ボタンを表示しない（practice モード時は不要）
- グリッド表示トグルボタンは常時青色にしない（ON/OFF状態を正しく反映）。ボタンサイズは他のボタンと揃える

---

## right-area

### プレイヤー情報パネル（practice モード時）

right-area 上部に P1/P2 情報パネルを表示（deckinfo/actions エリアを置き換える）。

```
+--[ Player 1 ]---[ Player 2 ]---+
| [thumbnail] デッキ名           | [thumbnail(空)] (未選択)  |
| [hard-reset][reset][open][save]| [open]                    |
+--------------------------------+
```

- **P1**: 現在のデッキのサムネイル・名前を表示。hard-reset/reset/open/save ボタン
- **P2**: 初期は空欄。open ボタンでデッキリストダイアログを開き、選択したデッキを P2 として設定
  - P2 デッキ選択時: P2フィールドが practice-area 上部からスライドイン
  - P1フィールドは下方向にスライドして2デッキレイアウトに移行
- **注意**: Draw 1/2・シャッフルなどのゲーム操作ボタンはこのパネルに置かない。それらはフィールドのスロットメニューまたはゾーン操作から行う

### zone info area（practice モード時）

- **ダイアログではなく right-area の practice tab 内**に表示する
- ゾーンをクリックしたとき、そのゾーンの情報・カード一覧を right-area に表示する
- カード画像は PracticeCard と同等のサイズ
- 各カードに操作ボタンをホバー時オーバーレイで表示
- ゾーン名とカード枚数をヘッダーに表示

### right-area からのカードドラッグ

- right-area のカードリスト内のカードを practice-area のゾーンへドラッグで追加できる
- 追加すると**一時レシピ**が生成される
  - hard-reset するまで一時レシピは保持される
  - save ボタンで保存するとその一時レシピが正式なデッキとして保存される
  - 一時レシピ状態では right-area 上部にその旨を表示

### その他タブの動作（practice 中）

| タブ | practice中の動作 |
|------|-----------------|
| Card | カードクリック・ホバーで詳細表示（既存機能そのまま） |
| Search | 検索結果のカードに「手札に追加」「場に出す」ボタンを表示 |
