# 一人回し機能 要件定義

## 概要

遊戯王NEXTに「一人回し機能」を追加し、特定条件下でのカードの動き方を確認できるようにする。

## 目的

**主目的**: コンボ確認、初動確認、カードの相互作用確認
**目的外**: 本番のデュエルシミュレーション、対戦相手の行動再現

### ユーザーがやりたいこと

1. デッキを回して初動の手札を確認する
2. 特定のコンボが決まるか手順を確認する
3. サーチ先のカードを確認する
4. 手札誘発のタイミングを確認する
5. 特定の場面を作ってカードの挙動を確認する

---

## 配置場所

デッキ編集ページおよびデッキ閲覧ページで、デッキレシピを表示している部分と切り替えて表示される。

---

## 画面レイアウト

### 1デッキモード

公式デュエルフィールドに準拠した配置。

```
+--------+----+----+----+----+----+--------+--------+
| Field  | M1 | M2 | M3 | M4 | M5 |  GY    | Banish |
+--------+----+----+----+----+----+--------+--------+
| Extra  |ST1|ST2|ST3|ST4|ST5|   Deck   |
+--------+----+----+----+----+----+---------+
| [H1][H2][H3]...[Hn]               |  Temp  |
+---------------------------------------------+
```

| 行 | ゾーン | 説明 |
|----|--------|------|
| Row 1 | Field / M1-M5 / GY / Banish | フィールド魔法、モンスターゾーン(5枠)、墓地、除外 |
| Row 2 | Extra / ST1-ST5 / Deck | エクストラデッキ、魔法罠ゾーン(5枠)、メインデッキ |
| Row 3 | Hand / Temp | 手札、一時置き場 |

- 全ゾーンへの配置は自由（ルール判定なし）
- 2デッキモードは1デッキの対称構成を上下に配置

### 各ゾーンの表示仕様

**カードの表示状態:**
- 表向き（通常表示）
- 横向き（守備表示等）
- 裏向き（半透明で表示、内容は見えない）
- 重ね表示（右上/左上/右/左にずらしながら重ねる、枚数表示付き）

**デッキの表示:**
- メインデッキ: 裏向きでずらさずに重ねる。内容は原則非公開。手動で上・下に配置したカードのみ表示される。内容確認時はチェックボックスを挟んで一時的に表示
- エクストラデッキ: 裏向きでずらさずに重ねる。内容は確認可能
- どちらにも手動で表向き/裏向きカードを上・下に追加可能

**墓地/除外の表示:**
- 上位数枚をプレビュー表示
- ボタン押下で展開して全体を確認可能

**一時置き場（Temp）:**
- 手札の右側に配置
- カードを一時的に置けるエリア

### カードサイズ

手動設定（プリセット選択を設定画面で切替）

## 操作設計

### スロット単位の操作

各ポジション（スロット）のカード左上に配置:
- **クイック操作ボタン**: 代表的な操作（ドロー、墓地へ等）
- **メニューボタン**: ダイアログを開き、重なっているカード全体の表示と各種操作

### カード単位の操作

ダイアログ内や個別カードに対しても操作可能。

### 基本操作

| 操作 | 説明 |
|------|------|
| ドロー | デッキの上から1枚を手札の右端に追加 |
| デッキから直接移動 | デッキの上から1枚を墓地・除外などに直接追加 |
| 手動配置 | 表向き/裏向きでデッキの上・下にカードを配置 |
| シャッフル | メインデッキ、手札、エクストラデッキそれぞれで可能 |
| 場に出す | 手札カードをモンスター/魔法罠ゾーンへ |
| 墓地へ | 任意のカードを墓地へ |
| 除外へ | 任意のカードを除外へ |
| 手札に戻す | 場のカードを手札へ |
| デッキに戻す | カードをデッキの上・下に戻す |
| 一時置き場へ | カードをTempエリアに一時退避 |
| リセット | 全て初期状態に戻す |
