# PracticeSlotMenuDialog リデザイン要件定義

## 現状の問題

1. カード画像が小さすぎる（30x44px）
2. アクションボタンがカード画像の上に小さすぎて操作困難
3. ドラッグでカードを移動できない
4. ゾーン内のカードをフィルタ/ソートできない
5. カードの情報確認（カード名など）が困難

## 要件

### カード表示
- カード画像は PracticeCard と同等のサイズで表示
- カード名を表示
- カードの情報は左上 info ボタンで確認可能（PracticeCard と同じ挙動）

### カード操作
- 各カードにアクションボタンをカード画像上にオーバーレイ表示（ホバー時）
- ドラッグ＆ドロップでカードを別ゾーンに移動可能
- ドラッグで PracticeField のゾーンにドロップできる

### フィルタ/ソート
- カードタイプ（モンスター/魔法/罠）でフィルタ
- カード名で検索フィルタ
- ソート: カード名、カードタイプ

### UI
- ダイアログ形式（現状維持）または RightArea の Practice tab 内で表示
- カードはグリッド表示
- ゾーン名とカード枚数をヘッダーに表示
