# v0.7.1 (2026-09-03)

## New Features

- デッキのインポート/エクスポートダイアログを全面刷新。インポートは「Replace / Add / New Deck」の3択モードに対応し、プレビューは実際のデッキ画像生成機能を使った画像表示とテキスト表示を切り替え可能に。エクスポートはCSV/TXTのプレビューをその場で確認でき、CSV出力カラム（Section/Name/CID/CIID/ENC/Qty）はトグルON/OFF・ドラッグ並び替えに対応。CSVインポートもヘッダー列名ベースの解析に変更し、列の並び替え・間引きに対応した
- デッキメタデータタブに「Auto Rename」「Auto Category」ボタンを追加。Auto Renameは先頭の`[OCG]`等のレギュレーションタグを保持したままカテゴリに応じてデッキ名を自動生成し、カテゴリ未設定の場合はカテゴリの自動設定も行う。Auto Categoryはカテゴリの自動設定のみを行う
- デッキ画像作成ダイアログ: 前回の色/QRコード/サイドデッキ含める/フッターテキストの設定を保持するようになった。ダイアログの大きさが画面サイズに追従するよう調整し、ライブプレビューの解像度も向上

## Bug Fixes

- カードテキストがHTMLタグのまま生表示される問題を修正（`<br>`による改行の欠落、`{{カード名|cid}}`形式のカードリンクテンプレート未パース、FAQ補足情報内で二重エスケープされた`<a>`タグが実体化されないケースを含む）
- デッキ画像プレビューダイアログの縁取り実装により、プレビュー画像が生成画像より縮小表示される問題と、エクスポートした画像自体の縁に意図しない色が焼き込まれてしまう問題を修正
- 検索実行中にフィルター条件ダイアログで条件を変更すると、検索結果のフィルタリングや検索履歴が新旧フィルターで不整合になるレース条件を修正（検索開始時点のフィルター内容を検索完了まで一貫して使用するよう変更）
- 検索履歴: 空クエリ+フィルターのみの検索が完了する前にフィルター条件を全てクリアすると、完了した検索が履歴に登録されない問題を修正
- デッキインポート（Replaceモード）で、置き換え前のカード表示順序情報が残ったままになり旧カードが表示され続ける問題を修正
- デッキインポート時、カード追加の失敗（上限超過・無効なイラスト違い指定）を無視して追加件数にカウントしてしまう問題を修正。スキップした件数はトーストで通知するよう改善
- デッキCSVエクスポートでSection/CID/Quantity列を無効化でき、このアプリで再インポートできないファイルを作成できてしまう問題を修正（必須列はトグルできないよう固定）
- 「Save as New Deck」（旧Copy Deck）で生成されるデッキ名の「COPY_」が、先頭のレギュレーションタグ（`[OCG]`等）より前に付いてしまう問題を修正
- カテゴリラベルの取得が常に日本語固定だったため、日本語以外の表示言語でAuto Set Categoryによるカテゴリ自動判定が正しく動作しない問題を修正
- Auto Rename Deckが生成するデッキ名がデッキ名の文字数上限（50文字）を超過しうる問題を修正

## Changes

- デッキ三点メニューの「Copy Deck」を「Save as New Deck」に改称（挙動に変更はない）
- 設定ダイアログ・インポート/エクスポートダイアログの大きさを画面サイズに応じた高さに統一し、タブ切り替え時の大きさのばらつきや残像表示を解消
- カテゴリ・タグ・コマンド履歴等のバッジ/チップの配色を統一
- 確認ダイアログの表示・非表示にフェード＋ポップのアニメーションを追加し、保存完了後の画面遷移が唐突に感じられる問題を解消

## Refactoring

- カテゴリマッチング処理を`useCategoryMatcher`composableに切り出し

## Internal Improvements

- `AppSettings` / `UXSettings` のデフォルト値を `configs/app-settings.toml` / `configs/ux.toml` に一元管理。feature flag（`configs/features.toml`）と同様にビルド時に注入する方式へ移行し、設定デフォルト値の `src/types/settings.ts` 直書きを廃止。`docs/feature/*.toml` は category/UI導線のメタ情報専用に分離し二重管理を解消
- テストのconditions.tomlのsource_hash/verified_atが実装内容とずれていた問題を修正
