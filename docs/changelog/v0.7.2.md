# v0.7.2 (2026-09-17)

## New Features

- デッキ閲覧モードにregulation切替機能を追加。閲覧画面・編集画面の双方でレギュレーション（OCG / GENESYS / OCS等の代表区分+PAST区分）を手動切り替え可能にした。PAST区分は年グループ→個別版の2段階展開で、折りたたみ時は「OCG PAST（54）」の1行のみ表示。選択中のregulationに応じた禁止・制限カードのバッジ表示とGENESYSポイントのptティア色分けも閲覧画面で機能する（判定ロジックはregulation-card-badge.tsに一元化）

## Bug Fixes

- 拡張機能ページ表示時に、ロード画面より前に公式の元画面が一瞬表示される（チラつき）問題を解消。ロード画面（loader.js）をスタイル注入・描画前に早期表示する方式へ変更し、prefetch済みedit-uiモジュールでhash遷移した際にロード画面から先へ進まなくなる問題も修正
- デッキ画像作成ダイアログ: 生成画像が画面下方向にはみ出す・ダイアログを移動できない・画像の枠線やQRコードの位置が横方向に膨れるレイアウト問題を修正
- デッキ編集: 画面表示直後（初期化完了前・約1.1秒間）にCtrl+Z等のグローバルショートカットが無反応だった問題を修正。リスナー登録をデッキ描画前（onMountedのawait前）に前倒しした。あわせて初期化完了前にEscapeでグローバル検索モードに入ると、検索inputが非表示のため解除できずモードが残留する問題も修正（globalSearchのみ初期化完了後に有効化）
- インポート/エクスポート: ダイアログを再オープンした際にエクスポートファイル名（filenameBase）へ前回のタイムスタンプ付き値が残る問題を修正。再オープン時にデッキ名基準で再生成されるようにした（形式・Side Deck・CSV列設定は前回値を保持）
- インポート/エクスポート: CSV列のドラッグ&ドロップで元の位置へドロップした際に、ドラッグ中を示す列ハイライト（draggingクラス）が残存する問題を修正
- GENESYS: カードDBが逐次充実する状況で、ローカル再解決（reresolveLocal）で一部カードのみ解決できた際の改善結果が破棄され、新たに解決可能になったカードのポイントが再試行TTL（6日）経過まで表示されない問題を修正。部分解決結果もincomplete:trueのままキャッシュへ反映・返却するようにした（ensureList/ensureCurrentList/forceUpdateの3箇所）

## Changes

- GENESYSポイント取得を再設計: キャッシュに取得元の生entry（rawEntries）を保持し、カードDB追加分は外部再fetchなしのローカル再解決で反映するようにした。解決未尽くし（incomplete）時の外部再fetch間隔を見直し、デッキ閲覧ページでも同一ページ内でカードDB追加分を反映するよう解決順序を変更
