# 次期バージョン（未リリース）

## New Features

- **ソート順序のオプション追加**: レベル/ランク/リンクのソート順に「降順」「昇順」「降順/昇順（トグル）」の3つから選べるようになりました。「降順/昇順」を選択すると、5秒以内に連続してソートを実行した場合に昇順に切り替わります。

## Bug Fixes

- **ペンデュラムテキストの誤表示修正**: 非ペンデュラムカード（レッドデーモンズドラゴン等）に誤ってペンデュラムテキストが表示される不具合を修正しました。カードデータ更新時にペンデュラムテキストが存在しない場合、既存のペンデュラムテキストをクリアするようにしました。

## Changes

- **魔法・罠のソート順序修正**: デッキソート時の魔法・罠の並び順を正しい順序に修正しました。
  - 魔法: 通常 → 速攻 → 儀式 → 永続 → 装備 → フィールド
  - 罠: 通常 → カウンター → 永続
