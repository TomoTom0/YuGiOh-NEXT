# v0.7.0 (2026-08-31)

## New Features

- GENESYSポイント制リミットレギュレーションを本番ビルドで有効化。`[GENESYS-YYMM]` タグによるレギュレーション自動判定・GENESYSポイント表示が本番でも利用可能になった（従来は開発ビルドのみ）

## Bug Fixes

- GENESYSリスト取得: 拡張機能インストール直後などカードDB（cardTableA）が未構築のタイミングでGENESYSリストを取得すると、ポイント未解決（incomplete）のキャッシュが保存されたまま最大6日間復旧しない問題を修正。incompleteキャッシュは10分TTLで再取得するようになった
- GENESYS機能フラグ: 旧バージョンの本番ビルドで設定変更した際に永続化された `genesys=false`（当時の開発ビルド専用扱いによる強制OFF値）が残存し、v0.7.0で本番有効化したGENESYSが既存ユーザーに反映されない問題を修正。UIを持たないフラグのため保存値をビルド強制値のアーティファクトとみなし、ロード時にデフォルト値で上書きするようにした
- デッキ画像ダイアログ: 色・サイドデッキ・フッターテキストを連続で変更した際、完了が遅れた古いプレビュー生成結果が新しい結果を上書きし、表示プレビューとダウンロード画像が一致しなくなる問題を修正（generation token導入）

## Repository Management

- リリースフローにgit tag/GitHub Release作成を必須化（release-prep skillのstep8/9を「オプション」から「必須」に変更。v0.6.4〜v0.6.12で8バージョン連続の作成漏れが発生していたため）

## Internal Improvements

- feature flagのデフォルト値を `configs/features.toml` に一元管理（Single Source of Truth化）。webpack（DefinePlugin）/ vitest（define）がビルド時に同ファイルから注入し、`src/types/settings.ts` への直書きと `import.meta.env.DEV` 直書きを廃止。`true` / `false` / `"dev-only"`（開発ビルドのみ有効）で表現する
