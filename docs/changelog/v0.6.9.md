# v0.6.9 (2026-03-04)

## New Features

- カテゴリ優先エリア内のソート順をオプション化（`categoryPrioritySortMode`設定）
  - **レベル順**（デフォルト）: 全体のソート設定（降順/昇順/toggle）に従ってレベル順でソート
  - **枚数の降順**: 採用枚数が多いカードを先頭に固定配置
- undo/redo操作内容の表示と履歴ダイアログを実装（tooltipに操作説明を表示、任意の履歴位置にジャンプ可能）
- Exportファイル名にタイムスタンプ付与オプションを追加（オプション設定でON/OFF切り替え可能）

## Bug Fixes

- カテゴリ優先エリア内の並び順がソート方向（降順/昇順）に連動していなかった問題を修正
- saveボタン押下時に常に再ソートが実行されてしまう問題を修正（sort済みの場合はスキップ）
- ペンデュラムモンスターのモンスター効果テキストがペンデュラムテキストで上書きされる問題を修正
- 新規カード追加時のモンスター効果テキストがペンデュラムテキストと同じになる問題を修正
- デッキ編集画面の進む・戻るボタンのtooltipが表示されない問題を修正（Teleport + position:fixedで対応）
- Export時のファイル名がdeck-undefinedになる問題を修正

## Changes

- 保存時のデフォルト動作をソートなしに変更（現在の表示順を維持）、フルソート・公式フォーマット保存オプションを追加
- Import/Exportダイアログのデザインを他のダイアログと統一（common.scss適用、theme prop追加）

## Refactoring

- CommandHistoryDialogのfutureクラス（undoneと同条件で冗長）を削除
- DeckEditTopBarのツールチップスタイルのデバッグ用ハードコードカラーをテーマ変数に置き換え

## Repository Management

- changelogのプレースホルダーテキストを削除
